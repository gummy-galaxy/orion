State · independent of kind

Done, deferred, blocked, and placeholder

Each option is drawn on the rail's sample face. The last card in every row is an unfinished placeholder, which should never read as done. The rail's State control applies the chosen option everywhere.

Source · independent of kind

Where a card came from

GitHub PR, GitHub issue, Jira issue, Figma reference, and a native step. Native cards carry no source mark, so the mark itself says "outside Orion".

Cards with more than one source

A card's kind comes from its primary ref, the one that drives its status: the PR when there is one, then the issue, then the ticket. A PR that closes an issue stays a PR card, and the issue, branch, and design link become extra sources, not a second identity. These options show the extras, drawn with the rail's coin style (Ink coin when the rail picks a style without coins). The PR has GitHub (PR and issue), hop, and Figma refs; the Jira issue is mirrored on GitHub.

Group membership

Where a card lives, without repainting it

The same six cards in two groups. G1 is today: the group tints each card's art, so kind and group compete for color.
